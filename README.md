# operacao-tecnoval
Sistema de gestão de estoque e operações Tecnoval.

## Como usar
1. Abra a página do GitHub Pages: https://elvisbth-arch.github.io/operacao-tecnoval/
2. Login inicial: usuário admin / senha tecnoval123
3. Abas: Consultar, Estoque, Entrada / Saída, Preparar Carga (com Peso Bruto por item), Mudar Localização, Inventário, Movimentações, Planilha
4. QR distribui sozinho Código / Lote / Peso / NF. Galpão e Bloco ficam vazios para digitar na mão.
5. Realocar não cria item novo.
6. Planilha: base estoque.csv (14.141 itens) + carga.csv.

## Como atualizar o GitHub
- Suba index.html, estoque.csv, carga.csv e README.md para a branch main
- Em Settings > Pages > Deploy from a branch > main / root > Save
